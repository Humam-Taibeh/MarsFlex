# تطبيق تحديث شاشة القرار

هذه حزمة تحديث لـ v0.10.0؛ لا تتضمن بيانات المشروع الكبيرة ولا تستبدل terrain.py أو geoscene.ts.

1. أغلق نافذة تشغيل MarsFlex.
2. فك ضغط الحزمة، وانسخ api.py وroute_trust.py ومجلدَي analysis وdocs إلى مجلد MarsFlex، ووافق على استبدال api.py.
3. انسخ ملفات frontend/src المرفقة إلى frontend/src في المشروع، واستبدل frontend/dist كاملًا بمجلد dist المرفق.
4. افتح المشغّل المعتاد. لن تحتاج إلى كتابة كود أو تثبيت مكتبة جديدة لهذه الإضافة.

الشاشة تبدأ بوضع القرار. إعدادات الوقت والأيض والكتالوج متاحة خلف Advanced؛ الأيض لا يفتح تلقائيًا. شريط الثقة يخص المسار الأزرق، ويتوقف عن عرض نتيجة قديمة عند تغيير الخطة.

مواد العرض الإنجليزية ومصادرها في docs؛ ONE_PAGE_EN.pdf صفحة واحدة، وVIDEO_30_SECONDS_EN.md نص الفيديو، وSEVEN_SLIDES_EN.md هيكل الشرائح. مدة الفيديو هدف تحريري وليست مدة مقاسة.

تحليل الحساسية غير مشغّل. راجع docs/SENSITIVITY_PROPOSAL_AR.md ووافق على النطاقات أولًا. لا تشغّل analysis/run_sensitivity.py الآن، ولا تحتاج إلى تشغيله بنفسك.

النسخة الاحتياطية السابقة لتعديل الواجهة مرفقة داخل review/MarsFlex_PreDecision_UI_Backup.zip. ملفات review سجلات مراجعة فقط ولا تحتاج إلى نسخها إلى التطبيق. بيانات التقرير من تدقيق محلي وليست شهادة سلامة بشرية.
